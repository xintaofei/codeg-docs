# Features

Codeg turns a pile of separate coding-agent CLIs into one workspace. Here's what it can do.

## Collaboration & aggregation

- [Multi-Agent Collaboration](/features/multi-agent-collaboration) — a main agent delegates to sub-agents of different types within one session
- **Conversation Aggregation** — import sessions from every [supported agent](/guide/supported-agents) into one unified workspace
- Parallel development with built-in `git worktree` flows

## Build & automate

- [Project Boot](/features/project-boot) — visually scaffold new projects with live preview
- [Automations](/features/automations) — save a composer setup as a headless, scheduled automation
- [Chat Channels](/features/chat-channels) — drive your agents from Telegram, Lark (Feishu) and iLink (Weixin)

## Documents & research

- [Office Documents](/features/office-documents) — create and edit `.docx` / `.xlsx` / `.pptx` with live preview
- [Scientific Research](/features/scientific-research) — bundled research skills any agent can invoke

## Manage & operate

- **MCP management** — local scan plus registry search and install
- **Skills management** — global and project scope
- **Git remote account management** — GitHub and other Git servers
- **Web service mode** — access Codeg from any browser for remote work
- **Runtime Logs** — live in-app log viewer with filtering and per-module log levels
- **Integrated engineering loop** — file tree, diff, git changes, commit, terminal

See [Deployment](/deployment/) for how to run Codeg on the desktop, a server, or in Docker.
