# Appearance

**Settings → Appearance** controls how Codeg looks. Changes save automatically.

- **Theme mode** — Follow system, Light, or Dark.
- **Theme color** — the accent palette: neutral, zinc, slate, stone, gray, red, rose, orange, green, blue, yellow, or violet.
- **Window zoom** — scale the whole UI (persists per device).
- **Fonts** — set the **Interface**, **Editor**, and **Terminal** font families (bundled sans/mono choices or a custom family), the **font size**, and toggles for **font ligatures** and **word wrap**.
- **Mode selection area** — show or hide the Code Development / Office Work quick-action cards on the new-conversation page.
- **Desktop Pet** — manage the optional desktop pet.
