# Settings

Codeg's **Settings** is a full-screen panel with a left sidebar and a content pane; opening it lands on **Appearance**. Here's every section and where to read more.

| Section | What it controls | Guide |
| ------- | ---------------- | ----- |
| **Appearance** | Theme, accent color, zoom, fonts, welcome cards | [Appearance](/settings/appearance) |
| **General** | Default terminal, rendering, delegation, feedback tools | [General](/settings/general) |
| **MCP** | Model Context Protocol servers | [MCP Servers](/features/mcp) |
| **Skills** | Custom per-agent skills | [Skills](/features/skills) |
| **Skill Packs** | Experts, Office, Science bundles | [Skills](/features/skills) |
| **Agents** | Enable & configure coding agents | [Agent Settings](/agents/) |
| **Model Providers** | Reusable API connections | [Model Providers](/agents/model-providers) |
| **Quick Messages** | Reusable composer snippets (drag to reorder) | — |
| **Shortcuts** | Custom keyboard shortcuts | — |
| **Version Control** | Git executable + Git/GitHub accounts | [Version Control & Git](/settings/version-control) |
| **Chat Channels** | Telegram / Lark / iLink bots | [Chat Channels](/features/chat-channels) |
| **Web Service** | Remote browser access (desktop only) | [Web Service](/settings/web-service) |
| **Runtime Logs** | Live log viewer & levels | [Runtime Logs](/settings/logs) |
| **System** | Network proxy, updates, language | [System](/settings/system) |

::: info
**Web Service** appears only in the desktop app — when you're already using Codeg through a browser it's hidden. For headless/server deployments, configure the equivalent with [environment variables](/deployment/configuration).
:::
