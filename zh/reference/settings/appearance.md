# 外观

**设置 → 外观** 控制 Codeg 的呈现方式：浅色还是深色、强调色、整体绘制的大小、各个区域使用的字体，以及一些额外功能。它是设置窗口默认打开的界面，这里的每一项改动都会自动保存并立即生效 —— 没有保存按钮，也无需重启。

## 主题模式 {#theme-mode}

一个下拉选择器 —— **跟随系统**、**浅色** 或 **深色**。*跟随系统* 会追随你的操作系统设置并随之切换；下方的文字会显示它当前解析出的*实际*主题。在桌面应用中，原生窗口也会随之切换。

## 主题颜色 {#theme-color}

用于按钮、强调元素和高亮的强调色调色板。共十二种预设 —— 标准的 shadcn 主题色，每种都是一个可点击的色块：

**Neutral** *（默认）* · Zinc · Slate · Stone · Gray · Red · Rose · Orange · Green · Blue · Yellow · Violet

选择后会立即为整个应用重新着色。

## 窗口缩放 {#window-zoom}

按离散档位缩放整个界面 —— 文字、控件和间距一并缩放：

**80% · 90% · 100%** *（默认）* **· 110% · 125% · 150%**

缩放比例**按设备**存储，因此大尺寸外接显示器和笔记本屏幕可以各自保留适合自己的大小。

## 字体 {#fonts}

三种相互独立的字体，每个区域一种。每一种都可以从一组内置字体族（分为 **Sans-serif** / **Monospace** 两组）中选择，或选择 **Custom…**，以指定你系统上安装的任意字体。内置字体仅在被选中时才加载。可设置的内容因区域而异：

| 区域 | 字体列表 | 字号 | 连字 | 自动换行 |
| ------- | --------- | ---- | --------- | --------- |
| **界面** | Sans + monospace | — | — | — |
| **编辑器** | Monospace | ✓ | ✓ | ✓ |
| **终端** | Monospace | ✓ | ✓ | — |

- **连字** 会为支持连字的字体开启编程连字（`=>`、`!=`、`>=`）；对于不支持的字体，该开关会自行禁用并加以说明。终端连字仅对内置的编程字体生效。
- 底部有一个**实时预览**，会用你当前的选择渲染一行界面文本、一段代码片段和一条终端命令 —— 让你在确定前先做比较。

这些设置所影响的编辑器和终端，就是[工作区](/zh/guide/workspace)中的那些。

## 模式选择区域 {#mode-selection-area}

一个开关 —— **在新对话页面显示**。它控制当你打开一个全新对话时，**代码开发 / 办公工作** 的快捷卡片是否出现在 composer 上方。保持开启即可一键使用欢迎界面的快捷操作 —— 它们会为 [Office](/zh/guide/office) 和 [Research](/zh/guide/research) 等技能填入一段起始提示词 —— 或者关闭它，得到一个简洁的 composer。

## 桌面宠物 {#desktop-pet}

一个可折叠的**桌面浮动伙伴**管理器 —— 停留在你屏幕上的动画精灵角色，同时兼作实时状态指示器，显示有多少个智能体会话正在运行、等待审批或出错。它默认处于折叠状态；标题旁的数字表示你拥有的宠物数量。

添加宠物有三种方式：

- **添加宠物** —— 提供你自己的精灵表：一张**带透明通道的 1536×1872 PNG 或 WebP**（与 Codex 兼容），外加一个 id 和一个显示名称。
- **从 Codex 导入** —— 拉取任何已安装在 `~/.codex/pets/` 下的宠物；没有时该选项被禁用。
- **宠物市场** —— 浏览并安装社区宠物，可按类别（物件、动物、人物、生物）筛选，并按最新、热门或浏览量最高排序。

每个宠物卡片都可以让你**设为激活**、**编辑**或**删除**（激活中的宠物无法删除），点击卡片可预览动画 —— 待机、奔跑、挥手、跳跃，以及各种会话状态姿势。**召唤宠物窗口** 会让激活的宠物浮动在你的桌面上。

::: info 浮动宠物仅限桌面端
召唤屏幕上的伙伴需要原生桌面窗口，因此 **召唤** 仅在桌面应用中出现。你仍然可以在[浏览器会话](/zh/getting-started/deployment)中构建和管理你的宠物库 —— 只是没有地方让它浮动而已。
:::

## 值得了解 {#good-to-know}

- **外观是本地的。** 这些是按机器保存的偏好设置 —— 缩放尤其如此 —— 并不属于任何同步的配置文件。在每台设备上各设置一次。
- **应用语言不在这里。** 界面语言位于[系统](/zh/reference/settings/system)界面，而非外观。
- **一切即时生效。** 本界面上没有任何控件需要保存或重新连接才能生效。
