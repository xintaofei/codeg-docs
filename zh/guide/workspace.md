# 工作区

工作区是你在 Codeg 中真正完成工作的地方。它把四样东西放在同一个屏幕上——智能体的**对话**、你项目的**文件**、它的 **git 更改**，以及一个**终端**——让提示、审阅、提交的整个闭环在同一处完成，无需在编辑器、diff 工具和 shell 之间来回切换标签页。

## 布局 {#the-layout}

桌面工作区是并排的**四列**，每一列都有自己的头部条，列与列之间由可拖动的细线分隔，细线从顶边一直贯穿到底部：

- **对话（最左）。** 你打开过的每个文件夹中的每个会话——既是你的历史记录，也是你开启新会话的地方。它们按项目分组，每个都带有一个实时状态圆点：*进行中*、*待审阅*、*已完成*。顶部的条上有**新建对话**、**搜索**、**自动化**以及视图选项。
- **对话（中间偏左）。** 智能体的对话记录，composer 停靠在底部。它的标签页在顶部，下方一条纤细的**详情头部**显示文件夹面包屑和该对话的标题。
- **文件（中间偏右）。** 你打开的文件的编辑器、diff 和实时预览——就在对话旁边，因此你可以在智能体做出更改时实时看到它们落地。它有自己的标签页条和一个文件路径详情头部。
- **辅助面板（最右）。** 一个带标签页的面板——**会话详情 · 文件 · 更改 · 提交**——容纳会话信息、项目树、你工作树中的更改和提交历史。当面板变窄时，这四个标签会折叠成一个下拉菜单。

**终端**在两个中间列的下方展开，底部的**状态栏**显示文件夹和对话数量、正在运行的后台任务、令牌用量，以及当前活动会话的智能体和分支。

这里没有横贯整个宽度的标题栏——取而代之的是两个**角落簇**，它们在面板开合时保持原位：左上角切换侧边栏并切换远程工作区，右上角是**终端**、**辅助面板**和**设置**。每个面板都可以通过拖动调整大小，当你需要空间时，侧边面板和终端可以折叠收起——**⌘B**（对话）、**⌘E**（辅助面板）、**⌘J**（终端）。在手机或狭窄的浏览器窗口中，侧边面板会变成滑入式抽屉。

## 文件夹与侧边栏 {#folders-and-the-sidebar}

左侧边栏是你的大本营：你打开过的每个**文件夹**（即一个项目目录），其对话都分组显示在其下方。打开一个项目文件夹即可添加（**⌘O**）。右键点击文件夹的标题栏（或点击其 **⋯**），即可看到你能对它执行的所有操作：

- **设为默认智能体。** 选择某个文件夹应使用的智能体，之后你在该文件夹中开启的每个新对话都会预选它。选择**无默认（使用全局）**可回退到你的全局选择。它只设定智能体——一旦该智能体连接，模型和模式仍由它提供。
- **更改颜色。** 为文件夹指定一种强调色，让它的分区在你同时处理多个项目时更醒目。该颜色会为侧边栏中的文件夹及其对话着色；但不会延续到标签页中。
- **设置别名。** 给文件夹起一个更友好的显示名称，而不改动磁盘上的任何东西——它会在侧边栏和对话头部显示为 *别名 [ 文件夹 ]*。把输入框留空即可清除它，回到原始名称。
- **导入本地会话。** 一键将本项目的过往会话从你已安装的智能体拉入工作区——这正是 Codeg 对话聚合的实际运作。→ [对话聚合](/zh/guide/aggregation) 介绍了它扫描哪些内容以及如何匹配。
- **管理对话。** 批量选择文件夹的对话，按智能体或状态筛选、更改其状态或删除它们。
- **在外部打开。** 在 Finder / Explorer / 你的文件管理器中显示该文件夹，或在该处进入终端（仅桌面版）。
- **从工作区移除。** 将文件夹移出 Codeg——它的标签页和终端会关闭，但磁盘上的任何内容都不会被改动。

文件夹的真实名称始终是它在磁盘上的目录名——这一点永远不变——但**设置别名**可以给它一个更友好的标签，而颜色和分组能帮你一眼区分各个项目。

## 开启会话——composer {#start-a-session-—-the-composer}

一切都从 **composer** 开始，它是对话底部的输入框。选择智能体、模型和模式，将它指向一个工作文件夹，输入提示词，然后发送。

- **智能体和模型。** 从你已启用的智能体以及该智能体提供的模型中选择。（智能体选择器会在你开启新对话时出现。）
- **模式。** 下拉菜单列出所连接智能体提供的模式——计划优先模式、接受编辑模式等等。这些都来自智能体本身，因此你看到的内容取决于你正在运行哪一个。
- **工作文件夹与分支。** 输入框下方的小标签显示智能体将在何处工作；你可以在那里切换文件夹或分支，或以无文件夹方式运行（*无文件夹模式*）进行快速对话。
- **+ 菜单。** 附加文件、插入已保存的**快捷消息**、在智能体工作时留下**实时反馈**、运行**斜杠命令**，或从 Experts、办公工作或科学研究技能包中加入一个**技能**。
- **富文本输入。** 输入 **@** 可提及文件、智能体、过往会话或提交；输入 **/** 使用斜杠命令。
- **发送、复刻、停止。** **Enter** 发送（**Shift+Enter** 换行）；**Fork & Send** 会为对话创建分支；当智能体运行时，发送按钮会变成红色的**取消**按钮。你可以提前输入，消息会**排队**，直到它准备好接收。

::: tip 审批来自智能体
Codeg 没有全局的"自动批准一切"开关。智能体的行动自由度取决于你选择的**模式**，以及它在任务中途弹出的**权限提示**（见下文）——因此控制权始终掌握在智能体自身的安全模型手中。
:::

## 跟随进展——对话 {#follow-along-—-the-conversation}

当智能体工作时，它的**对话记录**会实时流入：以格式化 Markdown 呈现的回复（包含代码、数学公式和图表）、它的推理过程，以及针对多步骤任务的实时**计划**清单。

- **工具调用**会显示为带状态标记的可折叠卡片——*等待审批*、*运行中*、*已完成*、*已拒绝*。Shell 命令会实时流式输出；重复的操作会折叠成一条摘要，例如"已运行 3 条命令"。
- **更改会以内联方式显示**为 diff，每条回复都附带一张**已更改文件**卡片，因此你无需离开对话就能确切看到智能体改动了什么。
- **权限提示。** 当智能体需要许可时——运行命令、应用编辑、执行计划——一张卡片会停靠在 composer 正上方：*"智能体请求许可以继续本回合。"* 它的按钮是智能体自己的选项（允许、拒绝等）。另一张单独的卡片则处理智能体向你提出的多项选择问题。
- **委派的工作。** 当一个智能体交接给另一个时，一个**子智能体**浮层会追踪被委派的会话——这正是[多智能体协作](/zh/guide/multi-agent)的核心。
- 每个回合结束时都会显示其**模型、令牌和时长**统计，你还可以将整个对话**导出**为图片、Markdown 或 HTML。

## 处理文件——编辑器、diff 与预览 {#work-with-files-—-editor-diffs-and-previews}

右侧面板中的**文件**标签页是你的项目树，以工作区为根；点击任意文件即可在中间的文件窗格中打开它。**拖动**某个条目可以重排项目或投喂智能体：把一个文件或文件夹拖放到另一个文件夹（或工作区根目录）上可**在磁盘上移动**它，或把它拖入 composer 可将它**附加**为下一条消息的文件引用——由拖放的目标决定是哪一种，无需任何修饰键。

- **编辑。** 文件会在完整的编辑器中打开。这里**没有保存按钮**——Codeg 会在你按下 **⌘/Ctrl+S**、编辑器失去焦点时，以及你停止输入几秒后自动保存；未保存的文件会在其标签页中显示一个 **`*`**。用 **⌘L** 可将一个文件或仅选中的内容发送给智能体。
- **Diff。** 智能体的编辑会以**只读 diff** 的形式打开——并排（**HEAD ↔ 工作树**）或作为内联的统一 diff，一次一个文件，带有更改计数和上一处/下一处导航。Diff 用于*审阅*；你通过 git 面板（见下文）提交，而不是逐行接受更改。
- **实时预览**在同一个窗格中打开：**Office** 文档（`.docx`、`.xlsx`、`.pptx`）会随着智能体编辑而渲染并刷新；**Markdown** 和 **HTML** 提供**预览 ⇄ 编辑源码**切换（HTML 仅在你选择启用时才运行脚本）；图片可缩放和平移。→ [Office 文档](/zh/guide/office)

::: tip 合并冲突拥有专属的编辑器
解决冲突会打开一个三栏合并编辑器——**本地**、**结果**、**远程**——在这里你*可以*逐块接受更改。这是唯一提供逐块控制的地方；在其他任何地方，diff 都保持只读。
:::

## 会话详情 {#session-details}

辅助面板默认打开在**会话详情**上——它是你所在对话的一览：标题和各种 id、正在运行它的智能体和模型、状态和当前 git 分支，以及实时的**令牌用量**（输入、输出、缓存和上下文窗口总量）连同耗时与时间戳。每个字段都有一个复制按钮；当没有聚焦任何内容时，它只显示*暂无活动会话*。

当你在一个项目文件夹中工作时，该标签页顶部还带有两个过去位于标题栏的控件：

- **分支选择器。** 显示当前分支并打开完整的 git 菜单——切换分支，以及提交、推送、拉取、获取、储藏、创建分支或 **worktree**，或管理远程仓库。→ [Git 与 Worktree](/zh/guide/git)
- **命令启动器。** 在终端中运行你保存的按文件夹命令——Codeg 会从项目的 `package.json` 脚本中为它们播种，**管理命令**可编辑该列表。在你保存一个命令之前，它显示为**添加命令**。

## 审阅与提交 {#review-and-commit}

右侧面板的两个标签页让版本控制触手可及：

- **更改**列出你工作树中的编辑——已跟踪和未跟踪的，附带每个文件的行数统计。你可以从这里打开某个文件的 diff、放弃某项编辑（**回滚**），或开始一次提交。
- **提交**显示带推送状态的历史记录，并让你创建分支、重置或推送。

提交会打开一个专用的**提交**窗口：勾选你想要的文件，写一条消息，然后选择**提交**或**提交并推送**。[会话详情](#session-details)中的**分支选择器**负责其余的一切——拉取、获取、储藏、worktree、远程仓库，以及切换或合并分支。

使用 worktree 的并行开发、远程账户以及完整的 git 工作流程都有各自的页面。→ [Git 与 Worktree](/zh/guide/git)

## 终端 {#the-terminal}

按 **⌘J** 可在你的工作文件夹中打开一个集成终端——一个真实的 shell，而非沙箱。你可以在标签页中打开任意多个。它专为那些你更愿意自己运行的命令而存在：启动开发服务器、检查输出、在智能体旁边运行一次性脚本。

## 标签页与多任务处理 {#tabs-and-multitasking}

中间区域采用**标签页**形式，因此可以同时打开多个会话：

- **对话标签页**可通过拖动重新排序，双击可**固定**。**⌘T** 打开新对话，**⌘W** 关闭标签页，**⌘Tab** 在它们之间循环切换。
- **文件标签页**追踪你在文件窗格中打开的文件、diff 和预览。

### 将多个会话并排平铺 {#tile-several-sessions-side-by-side}

右键点击任意对话标签页并选择**平铺显示**，即可将你*所有*打开的对话在单个视图中并排铺开。它不是固定的两栏分屏——而是**每个打开的标签页对应一个窗格**，并排排列，当它们放不下时可横向滚动。这就是你同时运行一支智能体舰队的方式：在一个里开启一项任务，在另一个里开启另一项任务，无需切换标签页就能看到每份对话记录并行流动。

- **窗格就是你的标签页。** 打开另一个对话（⌘T 或侧边栏）可添加一个窗格；关闭一个标签页可移除一个。平铺至少需要两个打开的对话才能生效。
- **自由混合项目。** 平铺的窗格不局限于单个文件夹——可以把来自不同项目的会话并排放在一起。
- **只有一个窗格是活动的。** 活动窗格——即 composer 和快捷键作用的那个——会以流动的渐变边框勾勒出来。点击任意其他窗格即可聚焦它。
- **随时退出。** 右键 → **退出平铺**会将你带回单标签页视图。

平铺是[多智能体协作](/zh/guide/multi-agent)的绝佳搭档：将主导会话与它启动的子智能体会话并排平铺，观看整个团队协同工作。

## 欢迎界面 {#the-welcome-screen}

在会话开始之前，对话窗格会询问**"你今天想做什么？"**，并在三个标签页中提供**快捷操作**——**代码开发**、**办公工作**和**科学研究**。每张卡片只需一键即可将一个现成的技能（对于办公和研究，还有一个提示词模板）放入 composer；任何尚未为你所选智能体启用的项目都会显示一个锁形图标，点击可跳转到启用它的位置。下方是智能体选择器和一条轮换显示的提示。

## 桌面版与浏览器版 {#desktop-and-browser}

无论你运行[桌面应用](/zh/getting-started/installation)还是在浏览器中打开 [`codeg-server`](/zh/getting-started/deployment)，工作区都是一样的。有几处不同：

- **文件。** 桌面应用使用原生文件对话框，并且可以*在 Finder / Explorer / 终端中打开*；在浏览器中，你则改为**上传**文件或**在服务器上选择文件**。
- **窗口与附加功能。** 自定义窗口控件和桌面宠物仅限桌面版；浏览器则增加了**登录**（你的访问令牌），以及连接断开时的重新连接提示。
- **远程工作区。** 桌面应用可以连接到远程服务器，此时它的文件操作会表现得像浏览器一样。

## 键盘快捷键 {#keyboard-shortcuts}

| 快捷键 | 操作 |
| -------- | ------ |
| `⌘/Ctrl B` | 切换对话面板 |
| `⌘/Ctrl E` | 切换右侧（会话详情 / 文件 / 更改 / 提交）面板 |
| `⌘/Ctrl J` | 切换终端 |
| `⌘/Ctrl T` | 新建对话 |
| `⌘/Ctrl K` | 搜索对话和文件 |
| `⌘/Ctrl W` | 关闭当前标签页 |
| `⌘/Ctrl Tab` | 在标签页间循环切换 |
| `Enter` / `Shift+Enter` | 发送 / 换行 |
| `⌘/Ctrl L` | 将当前文件或选中内容添加到对话 |
| `⌘/Ctrl S` | 保存当前文件 |

以上是默认设置；其中一些可以更改。
